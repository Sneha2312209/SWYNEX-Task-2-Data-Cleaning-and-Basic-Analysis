# SWYNEX-Task-2-Data-Cleaning-and-Basic-Analysis
Data cleaning and basic analysis of the SARS-CoV-2 biological genome dataset using Python and Biopython. This project includes nucleotide counting, GC content calculation, and sequence quality analysis using data from NCBI.
### 1. Introduction
This project focuses on data cleaning and basic analysis of a biological dataset using Python.

The aim is to understand biological sequence data, clean the data, and perform basic statistical analysis.

### 2. Dataset Information
- Dataset Name: SARS-CoV-2 Reference Genome
- Source: NCBI (National Center for Biotechnology Information)
- Accession Number: NC_045512.2
- Organism: SARS-CoV-2
- Data Type: Nucleotide Sequence
- Genome Length: 29,903 nucleotides
- File Format: FASTA

Dataset Link:
https://www.ncbi.nlm.nih.gov/nuccore/NC_045512.2

### 3. Objectives
1. To understand biological sequence data.
2. To identify missing or ambiguous nucleotide values.
3. To clean and organize the biological dataset.
4. To calculate nucleotide frequencies.
5. To calculate GC content.
6. To perform basic statistical analysis.

### 4. Tools Used
- Python
- Google Colab / Jupyter Notebook
- Biopython
- GitHub

### 5. Data Cleaning
The following steps will be performed:
- Load the biological sequence.
- Remove unnecessary spaces and line breaks.
- Convert nucleotide letters into uppercase.
- Identify ambiguous nucleotide characters.
- Prepare a cleaned sequence for analysis.

### 6. Basic Analysis
The following analysis will be performed:
- Total sequence length.
- Count of A, T, G and C nucleotides.
- Nucleotide frequency.
- GC content percentage.
- Identification of ambiguous bases.

### 7. Expected Outcome
The project will provide a cleaned biological sequence and basic statistical information about the SARS-CoV-2 reference genome.

### 8. Conclusion
This project helps in understanding the importance of biological data cleaning and basic sequence analysis. Python makes biological data analysis easier, faster and more organized.
